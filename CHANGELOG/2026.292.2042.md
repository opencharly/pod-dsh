# 2026.292.2042 — feat(skills): move the two `dsh` skill bodies to .agents/skills

## Summary

Moves the 2 `dsh` skill bodies out of the manifest and into the repo that owns them: `.agents/skills/<name>/SKILL.md`. Each `skill:` node keeps its routing metadata — `name`, `family`, `owner`, `description` — and no longer carries a body of its own.

The generator reads this shape already: `plugin-marketplace/candy/plugin-marketplace/skillfile.go` takes the body from the first declared tree that holds the file, defaults the id to the node name, and hard-errors when a node's inline `content:` disagrees with the file. That rule is what makes R5 mechanical rather than a convention to remember.

**Why the gate below is the generator and not `charly box validate`:** `box validate` reports no skills at all, and measured on these repos it still returns `rc=0` with a relocated `SKILL.md` deleted outright. It cannot see this change, so it is pasted for completeness and not as the proof.
