# 2026.280.0657 — feat(dsh-web): seed the dsh volume with the full experimental-feature web profile

## Summary

Update the `dsh-web` candy so the **deployed** config is the one this candy ships:
the full experimental-feature web profile (the four bundles), seeded into the
`dsh` volume at deploy time. Fixes the gap where a fresh pod had only dsh's bare
shipped default (base + dsh-web-app) and every experimental feature required
manual in-UI toggling.

### Why it needed a `data:` stage (not a build-time mkdir)

The candy declares a named `~/.dsh` volume. A named volume is mounted at runtime
and **shadows** any build-time file tree, so writing the profile in a build step
would be hidden. charly seeds a named volume from a candy `data:` entry — the
notebook-templates pattern — only when the volume is empty.

### The change

- `candy/dsh-web/web-profile/` — the four profile files (`package.json` listing
  the bundles, `cordis.yml`, `cordis.patch.yml`, `pnpm-workspace.yaml`).
- `candy/dsh-web/charly.yml` — a `data:` entry `src: web-profile, volume: dsh,
  dest: profiles/web`; plus a runtime check.
- `charly.yml` — an R10 check on the `check-dsh-pod` bed asserting the seeded
  manifest lists all four bundles.

The bundle set is exactly the four dsh ships and offers **switched off**
(`OPTIONAL_BUNDLES` in `dsh-app-boot`): `dsh-experimental-agent-team-profile`,
`-auto-review`, `-schedule-bundle`, `-voice-input-bundle`. charly's seeder is
`initial` (gated on volume emptiness), so a user's later edits are kept.
`node_modules` resolves from the globally-installed dsh, so only the four small
text files are staged.

The `dsh-tui` candy deliberately keeps its profile at `dsh-base` + `dsh-tui`:
those bundles cannot activate there (the dsh-TUI adapter rejects `root.effect`).

**Honest note (an earlier run taught this).** The FIRST run of the new check
(`2026.280.0649`) reported `SKIP … unresolved variables: DSH_HOME:-$H/.dsh` — the
command used `${DSH_HOME:-…}`, and charly substitutes a check command's `${...}`
tokens, so the step silently vanished (the class the candy's own comments warn
about). Commit `a4f5895` switched to brace-free `$DSH_HOME` with a shell fallback;
run `2026.280.0653` is the post-fix PASS above. The earlier PASS was therefore
**not** a real pass of this check; this one is.
